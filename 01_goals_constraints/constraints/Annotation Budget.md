# Constraint: Annotation Budget

The team can manually annotate a small evaluation or validation set when it creates clear research value.

Absolute practical ceiling: approximately 100 to 150 manually annotated samples.

Manual annotation should be used strategically for targeted evaluation, query relevance, tactical labels, or robustness analysis. The project should not depend on creating a large new dataset.
