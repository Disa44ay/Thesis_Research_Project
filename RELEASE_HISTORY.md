# Public Release Mapping

The repositories preserve the original historical v1-v5 snapshots, but the Git-facing public history is grouped into four synchronized semantic releases.

| Public release | Historical basis | Milestone |
|---|---|---|
| Release 01 | v1-v2 period | Foundation and Scope Formation |
| Release 02 | v3 | Evidence-Driven Candidate Validation |
| Release 03 | v4 | Scientific Lock and Re-verification |
| Release 04 | v5 plus verified post-v5 work through 2026-08-16 | Execution-Ready Proposal and Feasibility |

The public grouping does **not** erase the original version history. Historical v1-v5 remain provenance checkpoints, while the public releases are milestone labels for GitHub and synchronized project communication.
