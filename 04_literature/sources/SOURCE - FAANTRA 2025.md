# Source: Action Anticipation from SoccerNet Football Video Broadcasts, 2025

Primary paper: Mohamad Dalal et al., CVPR Workshops 2025.

## Verified claims
1. Introduces football broadcast action anticipation using five-second and ten-second anticipation windows.
2. Releases the SoccerNet Ball Action Anticipation dataset derived from SoccerNet Ball Action Spotting.
3. Introduces FAANTRA as a baseline.
4. Introduces anticipation metrics including temporal-precision and occurrence-oriented mAP variants.
5. The task is explicitly motivated for automated broadcasting, tactical analysis, and player decision-making applications.

## Project implication
Exact thirty-second future prediction is not required to create a meaningful forecasting problem. Short-horizon anticipation already constitutes a recognized research task.
