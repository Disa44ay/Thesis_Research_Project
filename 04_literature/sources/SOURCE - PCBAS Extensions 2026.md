# Source: SoccerNet 2026 PCBAS Extensions

Primary paper: Parthsarthi Rawat, 2026.

## Verified claims
1. Builds on FOOTPASS baselines for the SoccerNet 2026 Player-Centric Ball-Action Spotting Challenge.
2. Uses graph-based tactical context alongside per-player visual features.
3. Reports fusion of GNN-derived context into a sequence model and additional class-weighting and post-processing extensions.
4. Demonstrates that generic tactical-context integration is already an active approach in PCBAS.

The earlier candidate gap "add tactical priors to PCBAS" must be narrowed substantially or downgraded.
