# Source: SoccerNet Challenges 2026

Official SoccerNet challenge page.

## Verified relevant tasks
The 2026 challenge program includes Ball Action Anticipation, Visual Question Answering, Player-Centric Ball Action Spotting, and other football AI tasks.

The Ball Action Anticipation challenge describes predicting timing and type of ball-related actions within the next five seconds using preceding gameplay video.
