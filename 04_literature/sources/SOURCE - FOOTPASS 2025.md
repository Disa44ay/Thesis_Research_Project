Source: FOOTPASS, 2025

Primary paper: FOOTPASS, A Multi-Modal Multi-Agent Tactical Context
Dataset for Play-by-Play Action Spotting in Soccer Broadcast Videos.

Verified claims

1.  Introduces a player-centric or play-by-play action spotting
    benchmark in a multimodal, multi-agent tactical context.
2.  The work explicitly motivates using tracking, identification, and
    soccer tactical knowledge to support computer-vision predictions.
3.  The benchmark is intended to support reliable play-by-play data
    streams for sports analytics.

Project implication

Broad claims that tactical context is absent from player-centric action
spotting are unsafe.
