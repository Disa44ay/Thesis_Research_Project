# SOURCE: Seq2Event 2022

## Paper
**Seq2Event: Learning the Language of Soccer using Transformer-based Match Event Prediction**

KDD 2022. Authors: Ian Simpson, Ryan J. Beal, Duncan Locke, Timothy J. Norman.

## Relevance
1. Predicts future football events from sparse event streams.
2. Uses event-level spatial and contextual information.
3. It demonstrates that future football event prediction itself is not novel.
4. It does not use continuous full-player tracking plus visual video evidence for BAA.

## Novelty consequence
Never claim "future football event prediction" as the contribution.
