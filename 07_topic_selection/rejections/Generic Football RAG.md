Rejection: Generic Football RAG

Rejected idea

Build a generic natural-language RAG system over football video, events,
audio, captions, or player metadata.

Reason

SoccerRAG already demonstrates multimodal soccer information retrieval
using natural-language queries over augmented SoccerNet information.

What survived

A much narrower tactical, spatial, temporal, or player-aware retrieval
problem may still be publishable if it introduces a measurable retrieval
method and evaluation rather than only system integration.
